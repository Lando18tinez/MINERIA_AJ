Orden de ejecución del pipeline

El orden importa: cada paso depende de que el anterior ya esté aplicado.

  1. Verificar duplicados — antes de transformar, para saber si hay filas que eliminar.
  2. Tratar nulos — la única celda vacía recibe una categoría explícita.
  3. Corregir tipos — años y cantidad a entero, para poder validar rangos y agregar.
  4. Estandarizar texto — antes de homologar: «Bogota D.C.» y «BOGOTA» deben escribirse igual para compararse.
  5. Homologar categorías — etiquetas legibles de combustible y llave municipio + departamento (requiere el texto normalizado).
  6. Validar rangos — reglas sobre las variables ya tipadas; marca, no altera.
  7. Marcar atípicos y año parcial — último paso, con indicadores, sin eliminar nada.

import re, unicodedata

def canonico(t):                                   # MAYÚSCULAS, sin tildes ni signos
    if pd.isna(t): return t
    t = "".join(c for c in unicodedata.normalize("NFKD", str(t)) if not unicodedata.combining(c)).upper()
    return re.sub(r"\s+", " ", re.sub(r"[^A-Z0-9 .]+", " ", t)).strip()
